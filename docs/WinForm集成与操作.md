# WinForm 集成与操作

本文说明怎样把授权窗体接到已有的 .NET Framework 4.8 WinForm 程序里，以及窗口打开之后，客户和支持人员在各种情况下按什么顺序操作。

这扇窗体只处理单机许可。机器池、浮动、加密锁、导入老码不要走这扇窗体。

## 1. 集成时用哪一部分

`src/Licensing.WinForms` 现在是一个可以直接运行的测试程序，里面同时放着要集成的窗体。接到你的软件里时，用这些公开类型：

| 类型 | 作用 |
| --- | --- |
| `SingleMachineLicense` | 读本机机器码，做离线检查、联网激活、导入文件、换机、重新检查 |
| `LicenseForm` | 授权窗口。`Ensure` 用在启动，`Show` 用在菜单 |
| `LicenseNames` | 把版本代码、功能代码显示成你的中文名 |
| `PublicKeyRing` | 读取随程序发出的 `public-keys.json` |

同项目里的 `Program`、`TestShell`、`App.config` 只给测试程序自己用。不要把测试程序设成你的软件的启动项，也不要照抄里面的 `demo.product`。

窗口上的固定文字在 `LicenseForm.resx`。布局在 `LicenseForm.Designer.cs`。激活、导入、换机的判断在 `LicenseForm.cs`。设计器要能打开，`InitializeComponent` 里只能写一条条属性赋值。

无参数的 `new LicenseForm()` 是给 Visual Studio 设计器准备的。你的程序要使用带许可对象的构造，或下面的 `Ensure` / `Show`。

## 2. 先用测试程序走一遍

服务器已在 `http://localhost:5277` 运行时，在仓库根目录执行：

```powershell
dotnet run --project src/Licensing.WinForms
```

测试程序默认产品标识是 `demo.product`，公钥会找到 `src/Licensing.Server/storage/public-keys.json`。演示库里的单机许可码是 `ABCDE-FGHJK-LMNPQ-RSTUV-WXYZ2`。把它贴进窗口，点「联网激活」，再点「进入程序」。主窗口菜单「授权」可以再次打开同一扇窗体。

要改成你的产品时，编辑 `src/Licensing.WinForms/App.config` 的 `ProductId`，例如 `金石眼镜软件`。版本和功能的中文名写成 `代码=中文名`，多项用分号隔开。

这一步只为确认服务器、公钥和窗体本身是通的。通过之后再接到你的工程。

## 3. 接到你的 WinForm 工程

下面按 Visual Studio 2026、工程目标框架 .NET Framework 4.8 来写。你的工程保持为启动项目。

### 3.1 准备公钥和产品标识

1. 在授权后台用超级管理员打开「产品目录」，记下产品标识。它要和程序里的字符串逐字相同，例如 `金石眼镜软件`。
2. 为这个产品准备版本代码和功能代码。窗口上的中文名由你的程序提供，后台只认代码。
3. 从服务器目录 `src/Licensing.Server/storage/public-keys.json` 复制一份。这是公钥，可以随安装包分发。不要复制 `storage/keys` 里的 PFX，也不要复制 `signing-password.txt`。
4. 生产环境的服务器地址使用 HTTPS。开发阶段可以暂时写 `http://localhost:5277`。

换过签名密钥之后，把新的 `public-keys.json` 放进以后发出的版本。已经安装的旧版本只要还带着旧公钥，仍能验证旧授权。

### 3.2 把项目加进解决方案

1. 在你的解决方案里选「添加」→「现有项目」。
2. 选 `Licensing.slnx` 同目录下的 `src/Licensing.Client/Licensing.Client.csproj`。
3. 再添加 `src/Licensing.WinForms/Licensing.WinForms.csproj`。
4. 在你的 WinForm 工程上选「添加」→「项目引用」，勾选 `Licensing.WinForms`。客户端库会跟着被引用。
5. 解决方案的启动项目仍选你的程序，不要选 `Licensing.WinForms`。

你的工程若是老式 `packages.config`，项目引用传不过 NuGet 依赖。这时改为：

1. 先编译 `Licensing.WinForms`。
2. 在你的工程里安装 NuGet 包 `System.Text.Json` 8.0.5。
3. 引用编译结果里的 `Licensing.WinForms.dll` 和 `Licensing.Client.dll`，以及该 NuGet 包带出的 DLL。

很多 WinForm 是 32 位进程。授权窗体读机器码时打开的是 64 位注册表视图，避免进到没有 `MachineGuid` 的 `Wow6432Node`。你的工程可以继续用 x86 或 AnyCPU。

### 3.3 让公钥跟着程序走

把 `public-keys.json` 放进你的工程，生成操作设为「如果较新则复制」。运行后它出现在 exe 旁边。也可以嵌进资源，用 `PublicKeyRing.Parse` 读字符串。两种做法选一种，程序里的路径要和你放置的位置一致。

### 3.4 启动时先检查授权

在 `Program.Main` 里，`Application.Run` 之前做一次检查。进程内只建一个 `SingleMachineLicense`，退出时释放。产品标识换成你的，服务器地址换成你的。

```csharp
using System;
using System.Collections.Generic;
using System.IO;
using System.Windows.Forms;
using Licensing.Client;
using Licensing.WinForms;

static class Program
{
    [STAThread]
    static void Main()
    {
        Application.EnableVisualStyles();
        Application.SetCompatibleTextRenderingDefault(false);

        var names = new LicenseNames(
            new Dictionary<string, string> { { "pro", "专业版" } },
            new Dictionary<string, string> { { "export", "导出" } });
        var keys = PublicKeyRing.Load(Path.Combine(Application.StartupPath, "public-keys.json"));

        using (var license = new SingleMachineLicense(
            "https://license.example.com",
            "金石眼镜软件",
            keys,
            names,
            storeRoot: null,
            appVersion: Application.ProductVersion))
        {
            if (!LicenseForm.Ensure(null, license))
                return;

            Application.Run(new MainForm(license));
        }
    }
}
```

`Ensure` 先做离线检查。本机已有有效的单机授权时不弹窗，直接进主窗口。还没有授权、已到期、已暂停或已吊销时，先弹出授权窗口。客户点「进入程序」才返回 true。点「关闭」或标题栏关闭，返回 false，主程序不要启动。

`storeRoot` 传 `null` 时，授权文件在：

`%LOCALAPPDATA%\Licensing\{产品标识}\grant.json`

许可码和拒绝记录在同目录的 `state.json`。要改根目录时，整个进程始终用同一个 `SingleMachineLicense`，也就是同一个 `storeRoot`。实际文件仍是 `{storeRoot}\Licensing\{产品标识}\grant.json`。

主窗体要保住这个对象，供菜单再次打开窗口：

```csharp
readonly SingleMachineLicense _license;

public MainForm(SingleMachineLicense license)
{
    _license = license;
    InitializeComponent();
}

void 授权ToolStripMenuItem_Click(object sender, EventArgs e)
{
    LicenseForm.Show(this, _license);
}
```

`Show` 在已经授权时打开只读信息，按钮是「关闭」。客户如果在这扇窗口里重新激活或导入成功，关掉之后主程序继续运行。

版本、功能字典里没有的代码会原样显示。字典的键是后台的版本代码和功能代码，不是中文名。

### 3.5 编译后看这几件事

1. 启动项目是你的程序。
2. 输出目录里有 `public-keys.json`。
3. 删掉当前用户下 `%LOCALAPPDATA%\Licensing\{产品标识}`，再启动，应先看到「尚未授权」。
4. 用一张单机许可码联网激活，点「进入程序」，主窗口出现。
5. 关掉程序再打开，不应再挡住主窗口。
6. 菜单「授权」能打开同一扇窗口，并看到版本、功能、许可码、许可到期日和离线可用至。

## 4. 客户在窗口上怎么操作

窗口上始终有本机机器码和「复制」。状态是一句中文。说明文字只讲当前这一步。底部灰色的「详细信息」是状态码，支持人员排查时让客户读出来即可，客户不用理解它。

「解除本机授权」不在这扇窗口上。换电脑时，在新电脑上操作，不必先在旧电脑上解除。

### 4.1 第一次使用，这台电脑能上网

1. 打开程序。窗口标题是「授权」，状态是「尚未授权」。
2. 把供应商给的许可码贴进「许可码」。
3. 点「联网激活」。
4. 状态变为「已授权」。窗口显示版本、功能，以及「许可到期」。
5. 点「进入程序」。

下次打开同一 Windows 用户下的程序，若离线可用至还没过，程序直接进入，不再弹出窗口。

「许可到期」的第一行是后台设定的日期，按 UTC 当天结束。你设成 2030-11-12，这里就显示 2030-11-12。永久许可这一行是「永久」。第二行「离线可用至」是这台电脑不联网时还能用到的时刻，从最近一次成功联网起算宽限天数，默认 7 天，所以刚激活后会看到大约 7 天后的本地时间。它不是激活时刻本身，也不会把许可到期日提前改掉。再次联网检查成功后，这一行会往后延，但不会晚于许可到期日。

### 4.2 第一次使用，这台电脑不能上网

1. 打开程序，状态仍是「尚未授权」。
2. 点机器码旁边的「复制」，把这串字符发给供应商。不要改任何一个字符，也不要加空格或换行。
3. 供应商在后台生成授权文件，把 JSON 文件发回来。生成方法见下一节。
4. 客户点「导入授权文件」，选中这个 JSON。
5. 状态变为「已授权」后，点「进入程序」。

在文件到期之前，这台电脑可以不联网。

### 4.3 供应商怎样生成那份文件

这一节给内部支持人员。客户看不到后台。

1. 打开「客户」，进入该客户。
2. 若还没有许可，点「签发许可」，种类选「单机」，选好版本和功能。签完后把 25 位许可码留给客户，供以后能上网时使用。
3. 在许可列表里点那串许可码。页头应是「单机 · 有效」。
4. 滑过上面的保存表单，以及「新机器码 / 后台换机」。那一行不下载文件。
5. 在「离线授权文件」里粘贴客户发来的机器码。
6. 文件到期日默认是今天起 365 天。这张许可若是订阅：先取消「永久许可」，填好到期日，点上方「保存」。保存成功后，「生成离线授权文件」右边会出现「直到订阅结束日」。需要盖满整个订阅时点它。永久许可没有这个按钮，手填一个日期。
7. 点「生成离线授权文件」。浏览器下载 `{产品标识}-offline.json`。把文件发给客户。

生成之后，同一页的「激活」表里应出现这串机器码。机器码若抄错，绑上的是错码。对该行点「强制释放」，再用正确机器码重新生成。

暂停、吊销的许可上没有这段。先恢复成有效，再生成。

### 4.4 已经授权后，从菜单再打开

1. 在主程序里打开你们放好的「授权」菜单。
2. 窗口状态是「已授权」，许可码只读，可以复制。
3. 看完后点「关闭」。主程序继续使用。

这台电脑上不要找「换到这台电脑」。换机按钮只出现在另一台电脑上，并且是在联网激活得到「许可绑定在另一台机器上」之后。

### 4.5 许可已经在别的电脑上，要换到这台

在新电脑上操作，需要能上网。

1. 打开程序，把原来的许可码贴进去。
2. 点「联网激活」。
3. 状态变为「许可绑定在另一台机器上」。阅读说明：换到本机会计入本年度自助换机次数。旧电脑上已经拷走的离线文件，在它自己的到期日前还能用。
4. 点「换到这台电脑」。
5. 成功后状态变为「已授权」，点「进入程序」。

同一台电脑解除后再激活，不算换机。这扇窗口不提供解除。

### 4.6 今年的自助换机次数用完了

1. 换机之后若状态是「已达到本年换机次数」，「换到这台电脑」按钮不能再点。
2. 复制本机机器码发给供应商。
3. 供应商在该许可详情里用「后台换机」填入这串机器码，或先「强制释放」再让客户重新联网激活。后台换机不占客户的年度次数。

窗口上看不到「还剩几次」。只有超额时服务器才会返回这句话。

### 4.7 许可码不对

状态是「没有这张许可」。说明是许可码不对，或不属于本程序。核对许可码和产品是否一致，改完后再点「联网激活」。

### 4.8 导入的文件不是这台电脑的

状态是「授权与这台电脑不一致」。这份文件里的机器码和窗口上的机器码不同。把窗口上的机器码重新发给供应商，等新文件后再点「导入授权文件」。

若这张许可码其实已在别的电脑上激活，也可以改点「联网激活」，再按第 4.5 节换到这台电脑。

### 4.9 文件和程序对不上

状态是「许可签名无效」。文件被改过，或程序里的公钥不是签发这台服务器的那一份。向供应商重新要文件，或在能上网时改用「联网激活」。

### 4.10 连不上授权服务器

还没有本地授权时，状态是「连不上授权服务器」。可以改走第 4.2 节：复制机器码，导入供应商发来的文件。网络恢复后也可以再点「联网激活」。

已经授权过、离线可用至还没到时，程序仍会进入。菜单里打开授权窗口，状态仍是「已授权」，说明里会多一句：刚才没连上授权服务器，在离线可用至之前可以继续使用。

### 4.11 授权到期

状态是「许可已到期」。

- 电脑能上网：点「重新检查」。订阅若还没结束，服务器会签一份新的到期时间。
- 只是离线文件到期、订阅或永久许可本身仍有效：把机器码发给供应商，再要一份文件，然后点「导入授权文件」。
- 若说明写的是服务器确认这份许可已到期：订阅已经结束。联系供应商重新签发，然后再点「重新检查」。不要导入原来的文件。

### 4.12 许可被暂停

状态是「许可已暂停」。联系供应商。供应商在后台点「恢复」之后，客户在这台电脑上点「重新检查」。不要在暂停期间导入原来的授权文件。

### 4.13 许可被吊销

状态是「许可已吊销」。联系供应商。已吊销的许可不能继续使用，也不要导入原来的文件。窗口上没有「进入程序」。

### 4.14 看到系统时间的黄字

黄字是「观察到系统时间比上次记录早。不影响本次使用」。把电脑时间改回正确即可。授权仍然有效，可以点「进入程序」。

### 4.15 客户关掉了授权窗口

启动时若没有点「进入程序」，而是点「关闭」或标题栏的叉，程序应当退出，不要进入主界面。已经在主程序里从菜单打开时，点「关闭」只关掉这扇窗口。

## 5. 集成时不要做的事

- 不要用测试程序的 `App.config` 当作你的产品配置。产品标识、服务器地址写在你自己的程序里。
- 不要在启动代码里调用无参数的 `new LicenseForm()`。
- 不要为浮动、加密锁、机器池、老码打开这扇窗体。若本地意外存进了其他种类，窗口会写明「本窗口只处理单机许可」，并且不让进入。
- 不要把 PFX 和签名口令放进桌面程序。
- 不要在客户电脑上删 `%LOCALAPPDATA%\Licensing\{产品标识}\state.json` 来绕过暂停、吊销或到期。那会清掉已经确认的拒绝记录。
